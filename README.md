# icloud-session has moved

The shared iCloud sign-in (icloud-session) is now part of **[iCloud for Omarchy](https://github.com/ferdousbhai/icloud-for-omarchy)**, in [`session/`](https://github.com/ferdousbhai/icloud-for-omarchy/tree/main/session), with its full history.

iCloud for Omarchy is Apple Notes, Photos and Find My as native apps for [Omarchy](https://omarchy.org) and any Arch Linux, sharing one Apple sign-in, published as one signed pacman repository:

```bash
curl -fsSL https://github.com/ferdousbhai/icloud-for-omarchy/releases/latest/download/install.sh | sudo bash
```

Updates arrive with `omarchy update`. This repository is archived and kept only so old links lead somewhere.
